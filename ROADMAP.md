# Espresso Roadmap

> **DRAFT** — this is a starting point for maintainers to edit, not a commitment.
> Dates and priorities are owned by the Espresso team. Open a discussion to propose changes.

This document exists so the community can see where Espresso is heading.

## Version policy

| Line | Status | Support |
|------|--------|---------|
| `1.0.0` | **Current** (since 2026-01) | Features, stabilization, fixes, and improvements. |

Espresso supports the **Java 21**.

## Now (in progress)

- Stabilizing the `1.0.0` API surface through point releases.
- Documentation appendages
- Triaging and reducing any future open issue / PR backlog.

## Next (under consideration)

After `1.0.0` release, I will put my focus on other ongoing projects but I will try to maintain this project later on.

## How to influence the roadmap

- **Discuss before large PRs** — open a [Discussion](https://github.com/lazyboy81/Espresso/discussions)
  or issue so we can agree on the design first.
- 👍 reactions on issues help us gauge demand.
- See [README → Contribute](./README.md#contribute) for contribution guidelines.
